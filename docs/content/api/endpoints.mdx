All paths below start with `https://api.exegia.co`. Click an operation to see its exact fields, response schemas, errors, and request playground.

## Availability

The `/corpora` routes support the corpus lifecycle, node and manifest edits, version restore, and direct read-only sharing. Project linking supports draft references and Text-Fabric verification; PDF and EPUB selections remain unresolved until their verification is implemented. AI routes have separate configuration and ongoing migration work.

The capability flags are limited: `hub_writable` refers to legacy storage, not the newer corpus lifecycle. For a protected action, check its documented requirements and actual response.

## Authentication key

**Public:** no token. **User:** Supabase user access token. **Service:** Corpora service token. **Public or user:** public ready corpora allow omitted credentials; private access requires an authorized user.

## Limits and response formats

Conversion uploads are limited to 3 MB and return ZIP files; a score-gated PDF result can contain a review report without Text-Fabric output. Initial corpus import accepts a `.corpus` file with shipped cache, up to 3,000,000 bytes. Detail pagination accepts `limit` 1–200. Other operations have their own documented limits.

Most routes return JSON. Downloads can return binary artifacts. Always check the HTTP status and Content-Type before parsing a response. See [testing and errors](/api/testing).

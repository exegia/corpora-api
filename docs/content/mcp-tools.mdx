The FastMCP server exposes four core-backed tools at `https://api.exegia.co/v1/mcp/`:

| Tool | Result |
| --- | --- |
| `check_xml_structure` | Source-hashed XML diagnostics |
| `check_tei_purpose` | TEI date and identifier policy report |
| `detect_text_language` | Language and dictionary selection evidence |
| `check_text_spelling` | Dictionary-backed spelling findings |

Clients must send `Authorization: Bearer <token>` when `CORPORA_API_TOKEN` is configured on the hosted service. Conversion uploads use the REST endpoints because they return binary ZIP bundles.

The separate documentation MCP endpoint at `https://docs.exegia.co/mcp` exposes `search`, `get_page`, and `list_pages`. It reads these docs and does not run core checks.
